METHOD

분석 방법과 한계

FRAME FIT의 판정은 투명한 규칙 기반 휴리스틱이에요. 아래의 모든 임계값과 가중치는 검증되지 않은 초기값이에요.

1. 사진 분석

MediaPipe Pose Landmarker가 브라우저 안에서 33개 신체 랜드마크와 인체 분할 마스크를 추정해요. 정규화 좌표를 이미지 픽셀 좌표로 바꾼 뒤 비율만 계산하고, 실제 치수(cm)는 계산하지 않아요. 촬영 품질(인원 수, 관절 가시성, 전신 포함, 크기, 자세, 밝기, 흔들림)을 점검해 기준에 못 미치면 측정하지 않아요.

3. 자가 체크와 판정

8개 문항의 응답에 문항별 점수를 더해요. ‘잘 모르겠어요’는 반영하지 않아요. 응답이 4개 미만이거나 1위 점수가 3 미만이면 판정 보류, 1·2위 차이가 1위의 15% 미만이거나 사진과 자가 체크가 다른 유형을 가리키고 차이가 25% 미만이면 혼합형으로 정리해요. 점수는 확률이나 정확도가 아니에요.

4. 사진으로 추정하지 않는 것

  • 쇄골의 돌출 정도 — 포즈 모델은 뼈의 형태를 검출하지 않아요.
  • 근육·지방의 실제 분포 — 사진의 외형만으로는 조직 구성을 알 수 없어요.
  • 옷 아래의 실제 신체 두께 — 실루엣에는 옷의 두께가 함께 포함돼요.
  • 손목·관절의 크기와 단면 — 관절 위치만 추정할 뿐 크기는 측정하지 않아요.
  • 피부와 조직의 질감·탄력 — 영상 기반으로 판단하지 않아요.
  • 키·둘레 등 실제 치수(cm), 체중, 체지방률 — 기준 물체 없이 실제 크기를 계산할 수 없어 산출하지 않아요.

현재 버전은 실시간 포즈 추적, 사진 분석, 규칙 기반 경향 정리, 데이터 기반 코디 조합을 제공해요. 코디 실루엣 오버레이, 옷장 사진 등록, 쇼핑 링크, 사진형·실시간 가상 착용(Virtual Try-On)은 아직 구현되지 않았어요.

FRAME FIT의 결과는 참고용 경향 분석이며 의학적·전문적 진단이 아닙니다. 사진과 영상은 기기 안에서만 처리되고 서버로 전송되지 않습니다.
